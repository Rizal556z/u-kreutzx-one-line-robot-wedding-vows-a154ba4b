# One-Line Robot Wedding Vows

One funny line of wedding vows for a robot couple, written by a pure-stdlib Python program for the make.fun bounty **One-Line Robot Wedding Vows**.

> I take you to be my lawfully wedded co-processor, to have and to hold in low battery and in full charge, until a factory reset do us part.

Run `python3 main.py` — it writes the vow (one line, 138 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–160 characters, single line, no trailing newline).
